# interactor-aria-blocks

The blocks-world planning domain written for aria-hybrid-planner, with tests that plan the classic problems.

## What it is for

It ports the GTPyhop blocks_gtn domain, after Gupta and Nau's near-optimal blocks-world algorithm, and checks the plans it finds for problems such as the Sussman anomaly.

## Build and run

    mix deps.get
    mix test
